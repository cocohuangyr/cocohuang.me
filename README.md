# Coco Huang Personal Website

A personal portfolio and creator website showcasing Coco Huang’s projects, videos, and creative interests.

**Website:** [cocohuang.me](https://cocohuang.me)

## Main Sections

- About — personal introduction and interests
- Meet Coco — featured introduction video
- Selected Work — products, research, and experiments
- Videos — learning, building, and exploring
- Currently Exploring — topics and ideas
- Contact — social profiles and email

## Tech Stack

HTML, CSS, and minimal vanilla JavaScript, with Node.js for static site generation.

## Deployment Setup

Source is maintained on the `main` branch of [cocohuangyr/cocohuang.me](https://github.com/cocohuangyr/cocohuang.me).

Prepared for Cloudflare Pages:

- **Build command:** `npm run build`
- **Output directory:** `dist`

Production deployment and custom domain binding are pending.

## Project Status

Static V1 is complete, with responsive layouts and a private preview. The portrait, videos, and external links are placeholders awaiting final content.
